# 搜狗输入法一键去广告脚本

适用于已安装并使用过搜狗输入法的 Windows 电脑。脚本会自动识别安装目录和版本，关闭广告通知、皮肤推荐和输入法推广，并禁用商业扩展。

## 使用方法

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，解压整个文件夹。
2. 双击 `apply.cmd`，在 Windows 提示时授予管理员权限。
3. 如需撤销，双击 `restore.cmd`。恢复和应用请使用同一个 Windows 账户。

脚本会保留首次运行前的设置，备份存放在 `%LOCALAPPDATA%\SogouInputAdBlock`。输入法升级后如果推广重新出现，可以再运行一次 `apply.cmd`。

## 影响范围

脚本按安装路径拦截商业扩展和更新程序。PDF 等商业扩展附加功能、自动更新以及搜狗内置手动更新会受影响。输入法核心和云候选程序不在拦截范围内。

已配置 Windows 软件限制策略的电脑，或无法通过启动检查的 Windows 环境，会显示错误并停止。脚本在本机执行，无需额外安装 PowerShell 或第三方工具。
